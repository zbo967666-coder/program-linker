# 程序联动助手

一个 Windows 桌面工具：检测用户选择的程序 A，
在它运行时自动打开用户选择的程序 B。

## 下载使用

前往本仓库 Releases 页面，下载“分享版.zip”。
解压到普通文件夹后运行“程序联动助手.exe”。

GitHub 自动生成的 Source code.zip 是源码包，
需要直接运行软件的用户请下载分享版 ZIP。

## 功能

- 自定义选择程序 A 和程序 B
- 每2秒检测一次，每次 A 运行只触发一次
- B 已运行时尝试恢复窗口，避免重复启动
- 支持后台工具和托盘运行
- 可选登录后自动运行
- 不修改目标软件的快捷键及配置

## 使用方法

1. 选择程序 A 的实际 exe。
2. 选择程序 B 的实际 exe。
3. 点击“保存并开始检测”。

关闭设置窗口后仍会在托盘运行。
完全退出请右键托盘图标，选择“退出助手”。

## 运行环境

Windows，需具备 .NET Framework 4.x 运行环境。

## 从源码构建

在 Windows PowerShell 中进入源码目录，执行：

    .\构建.ps1

编译成功后生成“程序联动助手.exe”。

## 已知限制

- 当前支持一组 A → B。
- 短于2秒的运行可能无法检测。
- 请选实际运行的 exe，避免只选择启动器。
- 部分受保护目录中的程序可能无法通过文件选择器选择。
- 无法读取进程路径时，会退回当前会话同名 exe 匹配。

## 隐私

配置保存在本地联动设置.xml中，包含所选程序路径。
请勿上传个人配置、配置备份和运行日志。
